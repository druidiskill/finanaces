finances bot

Telegram-бот для учета доходов/расходов с записью в Google Sheets.

Базовые столбцы в таблице:
1) timestamp
2) kind (income/expense)
3) amount
4) category_path
5) comment
6) user_name

Категории:
- Выбор через inline-кнопки из списка (отдельно для доходов и расходов).
- Можно добавлять новые категории (поддерживаются уровни через `>`).
- Список формируется из истории в Google Sheets.
- После выбора категории доступен список подкатегорий, а также кнопки "Добавить подкатегорию" и "Готово".

Лист "Цели":
- `id` — уникальный идентификатор строки.
- `parent_id` — `id` родителя (пусто для корневой цели).
- `path` — путь `Цель > Этап > Подэтап`.
- `type` — `goal` или `step`.
- `title` — название цели/шага.
- `status` — `todo` / `in_progress` / `done`.
- `due_date` — срок `ДД.ММ.ГГГГ`.
- `created_at` — дата создания `ДД.ММ.ГГГГ`.
- `updated_at` — дата обновления `ДД.ММ.ГГГГ`.
- `order` — порядок внутри одного родителя.
- `note` — комментарий/описание.
- `owner` — имя пользователя.

Подготовка:
1) Создать сервисный аккаунт Google, скачать ключ и сохранить в корне проекта как `google.json`. Выдать доступ к таблице.
2) Создать `.env` по образцу `.env.example`.
3) Установить зависимости.

Запуск:
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
